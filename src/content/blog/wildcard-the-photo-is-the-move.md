Wildcard 的出牌不該是三顆按鈕。你若能直接選「石頭」，就不必真的去找一顆。

所以對戰是這樣開始的：出門，拍下石頭、樹枝或樹葉，Vision API 判斷你出的是哪一種，再跟另一個人比。規則俗氣到不行。趣味全在那個「你得先拿到一個真的東西」上面。

---

第一版我把 Vision API 直接放在前端呼叫。key 躺在瀏覽器裡。這個撐了不到半小時。`analyzeImage` 搬進 Cloud Function，區域放 `asia-east1`，Firestore 的規則擋掉不該來的呼叫。判斷可以借雲，鑰匙不能跟照片一起交到每個開啟的頁面。

勝負一開始也寫在前端，兩個欄位各自加減。兩個人同時寫，就會搶。後來改由 `onBattleComplete` 這個 trigger 在後端結算，畫面只負責顯示。等待的時候加了載入動畫。Vision 要跑一下，畫面若只是卡住，人會以為這張照片沒被收下。辨識要做對，人也要感覺得到剛拍的那個東西正在變成這一手牌。

暱稱用 `nickname#xxxx`，同名可以並存，不必先經營一個唯一的帳號。這遊戲不需要你先成為某個人，才准蹲下去。

**你出的那一手，必須是照片裡的東西，不是選單裡的一個選項。**

## 收尾

按鈕比較好測，也比較好做。它會把整個產品做成一個不用出門的猜拳。我寧可讓辨識偶爾認錯一片樹葉，也不要給人一顆永遠認對的「樹葉」按鈕。

先不說了，我得去看還有哪條捷徑能讓人不出門就打完一場。
